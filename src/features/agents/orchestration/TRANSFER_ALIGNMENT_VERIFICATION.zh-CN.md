# 编排导入导出对齐验收

更新：2026-10-29。参照本地 `agent-open-cloud-protal` 的 AgentOrchestration、ImportAgentConfigDialog、ImportDifyDialog、DslFileDropzone 和 agentApi；未 fetch/pull。

## 范围与实现

工作流和对话式编排共用 `AgentTransferMenu`，使用项目 Button、Input、Dialog、DropdownMenu 和语义 token。

| 功能 | 对齐行为 |
| --- | --- |
| 导出 DSL | GET `/gpt/base/agent/exportConfig/{id}`，下载服务端已保存的 YAML，解析响应文件名；不自动保存本地修改 |
| 导入 DSL | 选择/拖拽 `.yml/.yaml`，明确提示覆盖当前配置，确认后 POST `/importConfig/{id}`，multipart 字段 `file`；导入后重载配置与调试状态，类型改变时切换编排路由 |
| 导入 Dify | POST `/importDify/preview` 预览不落库；POST `/importDify` 新建草稿，支持可选名称，成功按 flowType 跳转；不会覆盖原智能体 |
| 转换报告 | 模式、目标类型、节点映射数、DSL 版本；已转换、警告、跳过、待复核明细；默认名称回填、待复核数量提示 |
| 文件与状态 | 点击/拖拽选择、文件名/大小、移除与重新选择、扩展名校验；请求中禁止重复提交和关闭；错误留在弹窗中 |

接口参数保留可选 modelId，与参照一致，当前弹窗不提供模型选择器。Dify 资源转换由后端完成，前端展示绑定提醒，不自行补造资源映射。
