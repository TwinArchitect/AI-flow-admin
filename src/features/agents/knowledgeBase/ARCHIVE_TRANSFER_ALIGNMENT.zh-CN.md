## 实现对照

- 文件列表提供导入内容、导出内容，使用本项目 Dialog、Checkbox、Input、Button 和 token。
- 导出默认不含原始文件，可勾选包含；发送 includeOriginals，带共享登录鉴权，只有 ZIP 响应才下载，JSON/文本错误转为可读反馈；安全文件名及 object URL 清理。
- 导入仅接收 ZIP 选择，先 POST multipart file 至 import/preview，展示源/目标模型与维度、数量、警告及文档名称；校验前无最终提交入口。
- 确认时发送同一文件、sha256、targetModel、targetDimension，服务器负责内容和实际模型维度校验；换文件清预览/错误，提交失败清预览并要求重新校验。
- 操作期间禁止取消、关闭和文件修改；关闭重新挂载清状态。导入后第一页刷新文档、详情、统计、标签及分块缓存，接入任务进度并提示任务提交不等于生成完成。
- 未迁移参照外壳，未增加额外业务限制；不是智能体 DSL 的导入导出。
