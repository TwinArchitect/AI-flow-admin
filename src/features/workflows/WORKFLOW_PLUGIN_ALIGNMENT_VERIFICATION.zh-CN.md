## 范围

收尾审查后用户明确：保留本项目拖拽创建，不迁工具栏点击后居中创建；选择器确认流程与旧 nodes 配置兼容需要对齐，已补齐。

## 参照业务链路

- 查询本租户已发布的工作流型智能体，名称搜索，排除当前智能体。
- 读取目标 agentSetting；固定 userChatInput 入参，同步开始节点非系统变量及结束节点输出。
- 变量引用/常量输入映射；更换目标重置绑定，刷新 schema 按 key 保留绑定。
- workflowCall 模块保存与恢复，目标 agentId、publishedOnly、元数据及输入输出协议。
- 下游变量引用、错误捕获分支、运行执行详情。

| --- | --- |

## 二次源码审查

逐项对照选择器请求条件、排除当前智能体、目标配置读取、固定问题/自定义变量、结束输出与旧 inputs 回退、输入类型索引、引用数组、元数据、publishedOnly、catchError、错误输出、变量台账和运行详情。

补齐的细节：

- 系统 files 不作为自定义入参，自定义 file 字段保留。
- schema 刷新按 key 保留绑定和行 ID，避免参数重排后重新创建映射行。
- 刷新 schema 不覆盖用户自定义节点名称；更换目标仍更新名称并重置绑定。
- 元数据隐藏字段标签与参照一致；必填只识别实际布尔 true。
- 常量严格按 selectedTypeIndex 恢复，避免重新打开后被当成引用；arrayString 引用保持嵌套引用数组协议。
- 配置面板通过回调改名，避免 registry → panel → store 的模块初始化循环依赖。

新增一个节点契约测试文件，六项均通过：schema 推导、常量/引用/异常往返、刷新与替换、旧结束/输入模式兼容、arrayString 引用协议、旧 nodes 配置推导。测试不参与生产页面运行。
